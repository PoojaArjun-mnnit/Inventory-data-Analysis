# Inventory Data Analysis & Optimization

An end-to-end inventory analytics project focused on understanding demand patterns, inventory performance, procurement activity, and replenishment requirements using data-driven inventory management techniques.

## Project Overview

The project analyzes historical sales, purchase, inventory, and procurement data to identify:

- Demand patterns and inventory movement
- High-value and slow-moving products
- Inventory turnover and efficiency
- Optimal ordering and replenishment requirements
- Supplier lead-time and procurement inefficiencies
- Inventory carrying-cost opportunities

## Key Analyses

- Demand Analysis & Forecasting using historical trends and rolling averages
- ABC (Pareto) Analysis for inventory prioritization
- Inventory Turnover Analysis
- Economic Order Quantity (EOQ)
- Reorder Point Analysis
- Supplier Lead-Time & Procurement Analysis
- Inventory Carrying-Cost Analysis
- Process Improvement Recommendations

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Business Applications

The analysis supports decisions related to:

- Inventory prioritization
- Demand-driven replenishment
- Order quantity optimization
- Stockout prevention
- Inventory cost management
- Supplier performance
- Procurement efficiency
